# Foto Ritim v4.0 – Özgüler Forge

Fotoğraf + müzik seç → kesimler müziğin vuruşuna oturur → videoyu kaydet.

## Yayın
1. index.html, sw.js, manifest.webmanifest ve ikonları (icon-192.png, icon-512.png, icon-maskable.png, apple-touch-icon.png) HTTPS altında aynı klasöre yükle.
2. Telefonda aç: Android Chrome "Yükle", iPhone Safari Paylaş > Ana Ekrana Ekle.
3. Güncelleme yayınlarken sw.js içindeki sürümü (foto-ritim-vN) artır.
