# Ses Cebi (ozguler forge) — Güncel Paket

## Yapılan Yenilikler
1. **Açılış Logo Animasyonu:** Uygulama açıldığında sıcak nostaljik kaset amblemi (`ozguler forge · Ses Cebi`) yumuşak bir animasyonla belirip ana ekrana geçer.
2. **Düzenli "Cep Kaseti" Arayüzü:** Ses ekleme, oynatıcı ve kayıt listesi modüler ve dengeli kart yapısına oturtuldu.
3. **Ses Kesme (Kırpma) Özelliği:** Arşivdeki seslerin yanındaki makas (`Kes`) ikonuyla dalga formu üzerinden başlangıç/bitiş noktası seçebilir, `−1 sn` / `+1 sn` adımlarıyla hassas ayar yapabilir, seçimi ön dinleyebilir ve kesiti WAV formatında kaydedip indirebilirsiniz.

## Kurulum ve Çalıştırma
```bash
npm install
npm run dev
```

Üretim derlemesi almak için:
```bash
npm run build
```
