# Forge AI Vision (v2.5) - PWA Yapay Zeka Uygulaması

**Geliştirici:** Ozguler Forge  
**Web:** [ozgulerforge.com.tr](https://ozgulerforge.com.tr)  
**İletişim:** iletisim@ozgulerforge.com.tr

## Yenilikler
* **Fotoğraf Yükleme & Sürükle-Bırak:** Bilgisayarınızdan veya telefonunuzdan JPG, PNG, WEBP fotoğrafları sürükleyip bırakarak, `Ctrl+V` ile yapıştırarak veya **Fotoğraf Ekle** butonundan seçerek yükleyebilirsiniz.
* **Otomatik Görsel Optimizasyon:** Yüksek çözünürlüklü fotoğraflar kalite kaybı olmadan otomatik boyutlandırılır ve görsel analiz (Vision) destekli modellere (Gemma 4, Nemotron VL, GPT-4o, Claude 3.5 vb.) iletilir.
