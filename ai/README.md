# Forge AI - PWA Yapay Zeka Uygulaması

**Geliştirici:** Ozguler Forge  
**Web:** [ozgulerforge.com.tr](https://ozgulerforge.com.tr)  
**İletişim:** iletisim@ozgulerforge.com.tr

## Paket İçeriği
* `index.html`: Forge AI ana uygulama arayüzü ve OpenRouter akış motoru.
* `manifest.json`: PWA (Progressive Web App) kurulum ve uygulama kimlik dosyası.
* `sw.js`: Çevrimdışı önbellekleme (Service Worker) dosyası.

## Kurulum
1. Bu klasördeki 3 dosyayı sunucunuza veya GitHub Pages deponuza yükleyin.
2. Tarayıcıdan sayfayı açıp sol alttaki **Motor & API Ayarları** bölümünden `sk-or-v1-...` ile başlayan OpenRouter API anahtarınızı kaydedin.
3. Tarayıcı adres çubuğundaki veya menüdeki **Uygulamayı Cihaza Yükle** butonunu kullanarak cihazınıza kurun.
